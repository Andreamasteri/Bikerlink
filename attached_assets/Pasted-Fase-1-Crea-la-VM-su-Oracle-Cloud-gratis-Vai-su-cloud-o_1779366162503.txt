Fase 1 — Crea la VM su Oracle Cloud (gratis)
Vai su cloud.oracle.com → crea account Free Tier
Compute → Instances → Create Instance
Shape: VM.Standard.A1.Flex (ARM) — 4 OCPU, 24 GB RAM (tutto gratis)
OS: Ubuntu 22.04 LTS
Aggiungi la tua chiave SSH pubblica
Nella Virtual Cloud Network, apri le porte nel Security Group:
22 (SSH), 80 (HTTP), 443 (HTTPS)
Annota l'IP pubblico della VM
🌐 Fase 2 — Punta il DNS
Nel tuo provider DNS (es. Cloudflare), aggiungi un record A:

gh.bikerlink.app  →  <IP pubblico VM>

Aspetta qualche minuto che si propaghi.

🔐 Fase 3 — Genera il token segreto
Sul tuo Mac/PC (o direttamente sulla VM):

openssl rand -base64 32

Copia il risultato — è il tuo GH_TOKEN. Salvalo, ti servirà dopo.

🚀 Fase 4 — Esegui il setup sulla VM
SSH sulla VM, poi lancia il setup (tutto automatico, ~20-30 min):

ssh ubuntu@<IP-VM>
curl -fsSL https://raw.githubusercontent.com/your-org/bikerlink/main/graphhopper/setup-oracle.sh \
  | sudo DOMAIN=gh.bikerlink.app GH_TOKEN=<il-tuo-token> bash

Oppure — se preferisci clonare il repo prima:

git clone https://github.com/your-org/bikerlink.git
cd bikerlink
sudo DOMAIN=gh.bikerlink.app GH_TOKEN=<il-tuo-token> ./graphhopper/setup-oracle.sh

Lo script fa tutto da solo:

installa Java 21, Nginx, Certbot
scarica GraphHopper (~50 MB) + dati OSM Italia (~1.5 GB)
builda il grafo moto (~15 min)
configura HTTPS automatico con Let's Encrypt
avvia tutto come servizi di sistema con auto-restart
✅ Fase 5 — Verifica che funzioni
Dallo script viene stampato l'URL finale. Verifica con lo script di test già incluso nel repo:

./graphhopper/test-graphhopper.sh https://gh.bikerlink.app <il-tuo-token>

Deve uscire 7 PASS, 0 FAIL.

🔑 Fase 6 — Configura i segreti su Replit
Vai su Replit → Secrets e aggiungi:

Chiave	Valore
GRAPHHOPPER_URL	https://gh.bikerlink.app
GRAPHHOPPER_TOKEN	<il-tuo-token>
Poi riavvia il backend. Da quel momento il routing usa il profilo motorcycle reale — zero errori 400.
