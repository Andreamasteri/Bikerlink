🌐  4.  Backend — Endpoint REST
MetodoPathAuthFunzione
GET /api/expo-updates — Serve il manifest OTA (Expo Protocol v1, multipart/mixed). Slot-routing per device-id via expo-extra-params
POST /api/admin/ota/create Admin Crea una nuova release OTA con bundleUrl, metadata e status=pending
POST /api/admin/ota/:id/assign-slot Admin Promuove la release allo slot=stable. I client iniziano a riceverla al prossimo check
POST /api/admin/ota/:id/publish Admin Usato dal rollback: riattiva una release storica (status→active)
POST /api/ota/heartbeat — Riceve heartbeat post-load dal client (deviceId, releaseId, otaNumber). Conferma che il bundle è attivo
POST /api/admin/ota-error — Telemetria errori OTA (phase, source, errorCode, nativeStack, probe, networkInfo). Fire-and-forget dal client
